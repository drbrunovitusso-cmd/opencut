# Roteamento: qual meio para cada necessidade

Regra geral: escolher a ferramenta que entrega mais perto do final com menos retrabalho de marca, e somar meios quando cada um cobre uma camada diferente (veracidade, criatividade, dados, produção, memória). As ferramentas MCP são carregadas com ToolSearch. Se uma conexão falhar, dizer qual e usar a alternativa.

| Necessidade | Meio principal | Alternativa | Observação |
|---|---|---|---|
| Fonte científica | PubMed | site oficial (MS, OMS, IBGE, Vigitel) via WebFetch | sempre com ano e nível de evidência |
| Pesquisa ampla, tendência | WebSearch | skill deep-research | chegar à fonte primária |
| Métricas Instagram | Windsor.ai (`instagram`) | Metricool, Dalea AI | Supermetrics estava expirado |

## Combinações recomendadas

Carrossel educativo: PubMed + brainstorm + Dalea (variações de gancho) + Carroseia + revisor-cfm + banco.

Reels de bastidor: banco (lições) + roteiro do redator + OpenCut para cortar + Canva para capa + Metricool para horário.

Campanha: banco (pilares, aprendizados) + Windsor (desempenho anterior) + Dalea ou AdWhispr (referência) + estrategista + calendário no Google Calendar.

Análise mensal: Windsor + Metricool + banco relatorio + analista + aprendizados no banco.
